# 🎮 Epic Games Free Games Discord Bot

> **Автоматичний Discord-бот для отримання безкоштовних ігор з Epic Games Store та надсилання їх у вибраний канал!**  
> Залишайся в курсі нових халяв разом із твоїм сервером! 🚀

## ✨ Функціонал

- ✅ **Автоматичний моніторинг** безкоштовних ігор в Epic Games Store.
- ✅ Відправлення **гарних embed-повідомлень** з:
  - Назвою гри 🎮
  - Картинкою 🖼️
  - Коротким описом 📝
  - Прямим посиланням на сторінку гри 🔗
- ✅ **Планувальник (Scheduler)** для регулярних перевірок (щодня/щогодини).
- ✅ Гнучке налаштування Discord-каналу для надсилання повідомлень.
- ✅ Легка інтеграція та розгортання.

---

## 🚀 Швидкий старт

### 1. Клонувати репозиторій
```bash
git clone https://github.com/your-username/epic-games-discord-bot.git
cd epic-games-discord-bot
```
### 2. Налаштувати змінні середовища
```env
DISCORD_TOKEN=your_discord_bot_token_here
```
### 3. Запустити бота

## 💡Команди

### Використовуй <!status> для перевірки статусу.
### Використовуй <!freegames> для ручної відправки.
### Використовуй <!setgamechannel #НазваКаналу> для налаштування каналу для повідомлень.
